## High-level notes for the developer

- The profile screen is a full-screen overlay using the same slide-in pattern as `food-detail-screen` (`transform: translateX(100%)` → `translateX(0)` on `.hidden` removal). The animation logic mirrors that screen exactly.
- `Storage.getGoals()` and `Storage.saveGoals()` already existed before this session. The UI is new; the storage layer was already wired up.
- The global `.hidden { display: none !important }` rule in `styles.css` is a footgun — any new animated overlay needs a companion override or it will be permanently invisible. See the block around line 817.
- `renderDay()` is the function to call after saving goals — it reads fresh from `Storage.getGoals()` and re-renders the summary card.
